# 素材采集助手（浏览器扩展）

随 MiniMax H3 本地服务一起使用，不依赖任何网站。它只把通过 API 提交的公开网页交给本机服务，正文和可见评论以 Markdown 形式保存。

## 安装

1. 打开 `chrome://extensions`，开启右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录 `extensions/source-collector`。

安装后无需配对码，扩展会自动连接本机服务（`http://127.0.0.1:8000`）。

## 使用

1. 启动 MiniMax H3 本地服务（无需设置密钥）。
2. 点击扩展图标，先点“测试连接”，再点“开启”并在浏览器提示中允许网页读取。
3. 通过 `POST /v1/collections` 提交网址，扩展约每 30 秒领取一次任务，在新标签页打开网址，读取可见正文和可见评论，完成后关闭标签页。
4. 用 `GET /v1/collections/{id}` 查看状态，`completed` 后用返回的 `source_download_url` 下载 Markdown。

需要登录或验证时，任务状态为 `waiting_login`，标签页会保留在前台。请在该网页自行完成，然后再次提交同一网址。

弹窗中的按钮为「开启」或「关闭」，关闭后不再领取新任务。开启状态保存在扩展里，重启浏览器后保持不变。

## 安全说明

- 扩展默认捕获页面已加载的图片和完整视频响应（通过 Chrome 调试接口，浏览器会显示调试提示）。
- 不读取 cookie、本地存储、密码或隐藏表单字段。
- 不输入密码，不处理验证码，登录只能由你在原网页完成。
- 只读取页面可见的文字和已加载的资源，不会为了采集而额外请求图片或视频链接。
- 只允许公开的 http/https 网址（标准端口），拒绝本机和内网地址。
- 服务重启后，队列中未完成的任务需要重新提交。
